# BUILD-006 — Clients: workspaces isolés

## Objectif

SPEC §4. Chaque client se sent isolé.

## Scope IN

- Page par client: projets, contacts, meetings, CRM, fichiers, knowledge, policies, features
  actives, providers, agents, approvals, evidence, activité (onglets ou sections denses).
- Sélecteur de client global filtre TOUTES les zones (store scoping de BUILD-002).

## Acceptance

Changer de client ne laisse fuir aucune donnée d'un autre client (test store + vérif visuelle).

## Evidence

Screenshots de deux clients différents sur la même zone.
