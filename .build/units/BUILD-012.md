# BUILD-012 — Meetings
## Objectif
SPEC §9. Avant/après meeting, transcripts mock Fireflies.
## Scope IN
- Liste meetings par client; page meeting: AVANT (contexte, comms récentes, engagements, CRM,
  questions ouvertes, agenda suggéré) / APRÈS (décisions, engagements, tâches créées, faits,
  blockers, mises à jour suggérées, citations d'evidence vers le transcript).
- Flux visualisé: calendar event → prep → meeting → transcript → extractions → CRM → draft suivi.
## Acceptance
Une tâche extraite d'un meeting est liée dans Work avec provenance visible.
## Evidence
Screenshots avant/après + lien de provenance.
