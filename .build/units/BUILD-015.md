# BUILD-015 — Websites
## Objectif
SPEC §12. Déploiements toujours vérifiés.
## Scope IN
- Sites, pages, composants, déploiements, tests, issues; chaque déploiement montre: URL live (mock),
  réponse HTTP, test formulaire, test intégration, deployment ID.
- Créer un website build draft.
## Acceptance
Un déploiement sans vérification complète s'affiche comme NON vérifié (pas de faux vert).
## Evidence
Screenshots sites + déploiement vérifié vs non vérifié.
